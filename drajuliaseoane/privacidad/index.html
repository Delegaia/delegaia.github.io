Qué datos tratamos y para qué

Este sitio web no tiene formularios. Si contactas por teléfono, WhatsApp o Instagram, trataremos los datos que nos facilites (nombre, teléfono y el contenido de tu mensaje) únicamente para atender tu consulta y gestionar tu cita.

Base legal

Conservación

Los datos se conservarán el tiempo necesario para atender tu solicitud y, si pasas a ser paciente, durante los plazos que exige la normativa sanitaria.

Destinatarios

No se cederán datos a terceros salvo obligación legal. Al usar WhatsApp o Instagram, también se aplican las políticas de privacidad de esas plataformas.
